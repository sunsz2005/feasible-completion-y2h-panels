# Space-I 映射背景外部回顾性评价：评分前固定方案

2026-10-24。沿用已有算法与参数，不依据本次评价调整。此方案先冻结，全部面板封存后才解析评价边。

- 候选为历史 Space-I 清单经一对一映射得到的 6,277 个基因，按 Ensembl ID 排序；保留训练孤立点。候选定义独立于阳性端点。采用每个候选可分配 DB 或 AD 的模型假设，实际角色资格与序列等价未验证。
- 训练仅使用 HI-II-14，去版本号、无向去重、排除自环，限制于候选集合。训练不随机拆分。
- 评价为完整 HuRI TSV 中未出现于 HI-II-14、H-I-05 或 Test_space_screens-19 的无向非自环边，再限制候选集合。前两者排除既有报道，后者额外排除校准集合重叠。此差集表示数据库记录的新边，不证明筛查批次独立或首次发现年份。
- 固定总容量 200：DB、AD 各 100 个且互斥；每个面板 10,000 个潜在跨角色配对。覆盖函数为所选节点贡献 1，其余节点贡献 1-0.2^所选邻居数；覆盖下限为 coverage_order 参考集合覆盖的 98%。所有覆盖均按训练图计算。
- 确定性方法：coverage_partition、feasible_role_greedy（主方法）、role_blind（选择策略消融）。计时方法：multistart_roles、multistart_joint（主要强基线）、ep_adapter_repaired_swap、after_role_search。EP 是独立 EP-Prox-inspired 适配器，非作者代码复现。全部调用已有冻结实现。
- 公共预处理包括覆盖参考集合及其角色分配。主方法构造耗时作为四个计时基线的附加搜索时限；每个基线运行原有 20 个种子 20261020–20261039，顺序循环轮换。原实现时间容差 max(0.02 秒, 5%)，超时记录完整保留，无选择性重跑。role_blind 是不要求等时的消融。
- 一次生成 3+4×20=83 个面板，文件 SHA-256 完整封存后统一评分。已有项目曾查看这些公开图的数据规模，本次不能称为从未接触数据的盲法验证。封存控制的是本轮面板不依据评价分数选择。
- 主要指标：面板中角色相反的后续新增 HuRI 边数；报告全部方法、中位数、范围及相对主方法差值，同时复核训练目标、覆盖、100/100 容量、角色互斥与时间。20 次仅反映同一训练图下随机搜索及计时稳定性，不是 20 个独立外部样本，不做显著性检验。
- 不把未记录边当阴性，不报告精确率或实际命中率。新边计数是记录互作的面板容纳机会，不直接推断真实发现量或总实验费用。
- 停止规则：本轮固定方案只执行一次；所有结果完整报告。只有在主要强基线上获得可解释机会增量，才将其列为该设置下的外部支持。若主要比较未显示增量，保留描述性结果，先研究数据适配和角色资格，不针对本图调算法或筛掉不利基线。
